# Otomatik Kütüphane Yönetim Sistemi (OKYS)

Bu proje, kütüphane kitaplarının ve ödünç alma işlemlerinin yönetilmesi amacıyla hazırlanmıştır.

## Sınıflar
- Kitap: Kitap bilgilerini tutar.
- KitapKopyasi: Kitapların fiziksel kopyalarını temsil eder.
- Kullanici: Sistemdeki kullanıcı bilgilerini tutar.
- OduncKaydi: Ödünç alma ve teslim bilgilerini tutar.

## Kullanılan Teknoloji
- Java

## Proje İçeriği
- src: Java kaynak kodları
- doc: Kullanım durumu ve sınıf diyagramları
